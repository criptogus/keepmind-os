## Delivered

- Internal workspace package scope changed from `@agenteschat` to `@keepmind`, including consumers and lockfile.
- Product copy, current help, primary service hosts, default contact, export filename and email wordmark use KeepMind/Zero Agency. Default telemetry is off, push uses direct delivery, and upstream feedback relay is off.
- More contains Skills, Second Brain and Cybersecurity, also connected by local section navigation. Graphite surfaces, lime actions and current KeepMind characters retained.
- Skills offers the existing improvement proposal flow and optional SuperAgentSkill connection/catalog. Already connected accounts offer management, not another OAuth sign-in.
- Second Brain offers a downloadable JSON schema and prepared full objectives for a private GitHub brain or KeepMind SB installation. No memories are exported automatically. GitHub folders alone are explicitly not treated as privacy boundaries.
- Cybersecurity dispatches a preparation objective to the coordinator. It requires provider evidence of a paid Liquid subscription before activation, and authorization before target testing or credit use. It does not implement billing, purchase plans or launch scans from the page.

Legacy discovery identifiers, import formats, URL schemes, service IDs, environment variable names and cryptographic derivation labels remain where changing them would invalidate existing installations or data. These are compatibility internals, not product branding. This is not a claim that every literal upstream identifier was erased.
