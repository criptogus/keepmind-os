# Support

**[Issues in criptogus/keepmind-os](https://github.com/criptogus/keepmind-os/issues) are the support channel for KeepMind OS.**
Ask there about this fork: self-hosting, model keys, connectors, agent computers, development. The upstream
agentes.chat Discussions cover the upstream project, not this fork or keepmind.io.

Issues are for confirmed bugs and concrete feature requests (the issue forms will guide you).
Security reports go through [SECURITY.md](SECURITY.md), never a public issue.
